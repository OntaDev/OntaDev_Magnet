# OntaDev\_Magnet

**Автор:** OntaDev
**Лицензия:** MIT

Плагин добавляет новый предмет (голову со скином) и механику притягивания предметов вокруг игрока.

---

## ⚠️ Обязательная зависимость

Плагин **не запустится** без [OntaDev\_Libs](https://github.com/OntaDev/OntaDev_Libs) — общей библиотеки, на которой построена вся логика.

---

## 📌 Дополнительно

* Для корректной работы необходимо, чтобы у игроков был доступ к предметам и командам в соответствии с разрешениями.
* Магнит может находиться в руках, а также в слотах шлема, нагрудника, поножей или ботинок.
* Параметры магнита (радиус, сила, лимит) хранятся в NBT предмета — у каждого экземпляра они свои.

---

## ⚙️ Конфигурация

Плагин использует два YAML-файла в своей папке данных:

### `config.yml`
**Шаблон по умолчанию:** [src/main/resources/config.yml](src/main/resources/config.yml)

Основные настройки плагина: периоды работы и проверки производительности, лимиты CPU/RAM, требование прав, частицы, фильтр предметов, внешний вид предмета-магнита по умолчанию (радиус/сила/лимит, имя, лор, текстура головы).

### `messages.yml`

Все сообщения, отображаемые игрокам. Поддерживают HEX-цвета (`<#RRGGBB>`), именованные цвета (`<red>`, `<green>` и т.д.) и плейсхолдеры (`<player>`, `<material>`, `<type>` и др.).

## 🕹 Команды

| Команда | Права | Описание |
|---|---|---|
| `/magnet give <Игрок> <Сила> <Радиус> <Лимит>` | `magnet.give` | Выдаёт игроку предмет-магнит. |
| `/magnet enchant <Сила> <Радиус> <Лимит>` | `magnet.enchant` | Зачаровывает механикой магнита предмет в руке. |
| `/magnet remove` | `magnet.remove` | Снимает механику магнита с предмета в руке. |
| `/magnet edit` | `magnet.edit` | Открывает меню для точечной настройки магнита в руке (радиус/сила/лимит через чат-ввод). |
| `/magnet menu` | `magnet.menu` | Открывает админ-меню глобальных настроек плагина. |
| `/magnet reload` | `magnet.reload` | Перезагружает `config.yml` и `messages.yml` без рестарта сервера. |
| `/magnet filter enable\|disable` | `magnet.filter` | Включает/выключает фильтр предметов. |
| `/magnet filter status` | `magnet.filter` | Показывает текущее состояние фильтра. |
| `/magnet filter add [Материал]` | `magnet.filter` | Добавляет материал в список фильтра (без аргумента — предмет в руке). |
| `/magnet filter remove <Материал>` | `magnet.filter` | Удаляет материал из списка фильтра. |
| `/magnet filter change <whitelist\|blacklist>` | `magnet.filter` | Меняет режим фильтра. |

Дополнительно: `magnet.use` — право, требуемое для активации магнита в руках, если в `config.yml` включён `permission-required`.

Алиас команды: `/магнит`.

---

## 🖥 Админ-меню

* **`/magnet menu`** — глобальные настройки: период работы магнита, период проверки нагрузки, лимиты CPU/RAM, переключатели требования прав / частиц / фильтра.
* **`/magnet edit`** — настройка конкретного предмета в руке: радиус, сила, лимит. Изменения применяются сразу к NBT предмета.

Ввод числовых значений происходит через чат: меню закрывается, бот просит написать число в чат, после чего либо возвращает игрока в меню, либо сообщает об успехе.
